# Public-data comparison decision

A direct public-data comparison is not included in the primary analysis. The current
result is a deterministic, single-cell LFPy forward simulation of a detailed BBP
morphology using an explicitly defined homogeneous conductivity and virtual point
electrodes. Public extracellular datasets typically differ in morphology,
electrode geometry, tissue conductivity, referencing, filtering, sampling, and
biological variability. Without a dataset matched to these assumptions, a
numerical amplitude comparison would not be scientifically interpretable.

This remains a possible future extension. A valid comparison would require a
public dataset with documented extracellular electrode geometry and units, plus
a prespecified transformation or simulation-to-data calibration. The showcase
therefore treats the public-data comparison as **not feasible for the current
deadline**, rather than presenting an unmatched comparison as validation.
